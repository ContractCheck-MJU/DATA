# 법령 RAG 검색 성능 평가 및 개선 (법령 파트)

작성: 서제현 / 2026-11-21
대상: 법령 95건 → 청크 165개 → BGE-M3 1024차원 벡터 (기존 산출물 그대로 사용, 재임베딩 없음)

---

## 1. 활용 데이터

- 국가법령정보센터 공개 법령 원문 **95건**, 조문 단위 청킹 **165개 청크**
- 구성: 민법 34, 주택임대차보호법 17, 약관의 규제에 관한 법률 14, 주택임대차보호법 시행령 6, 공동주택관리법 6, 집합건물법 4, 신탁법 4, 공동주택관리법 시행령 3, 공인중개사법 2, 실화책임법 2, 부동산등기법 1, 공인중개사법 시행령 1, 민사소송법 1
- 판례는 이 평가에 포함하지 않음 (별도 담당)

## 2. 사용 모델 및 구현 방법

- 임베딩 모델: `BAAI/bge-m3` (revision `3069def033ce91d907258f9a830e442610dbfe0b`)
- **사전학습 모델 그대로 사용. 추가 학습·파인튜닝 없음**
- 풀링: CLS(last hidden state) → L2 정규화 → 내적 = 코사인 유사도
- 검색 단위: 청크 단위로 유사도를 계산한 뒤 **같은 조문의 최고 점수**를 그 조문의 점수로 사용 (문서 단위 랭킹)

## 3. 평가 설계

- 계약 조항 문구와 질문 형태를 섞은 **평가 질의 24개** 작성
- 각 질의마다 기대 근거 조문(gold) 1개를 지정하고, 함께 인용될 수 있는 조문은 대체 근거(also)로 별도 표시
- **strict**: 기대 근거만 정답 / **lenient**: 대체 근거까지 정답으로 인정
- 지표: Hit@1, Hit@3, Hit@5, MRR@3

> 기대 근거는 작성자가 지정한 것으로 법률 전문가 검수를 거치지 않았습니다. 일부 질의는 여러 조문이 함께 근거가 될 수 있어 strict 수치는 보수적으로 나옵니다.

## 4. 평가 결과

### 4-1. 기준 성능 (보정 전)

| 지표 | strict | lenient |
|---|---|---|
| Hit@1 | 62.5% (15/24) | 75.0% |
| Hit@3 | 70.8% (17/24) | 79.2% |
| Hit@5 | 75.0% | 83.3% |
| MRR@3 | 0.667 | 0.771 |

### 4-2. 실패 원인

틀린 질의를 보면 두 가지 패턴이 반복됐습니다.

1. **허브 조문 현상**: 주택임대차보호법 제3조의2(보증금 회수), 제6조의3(계약갱신 요구), 제3조의3(임차권등기명령)처럼 **분량이 길고 임대차 일반 어휘를 많이 포함한 조문**이 내용과 무관한 질의에서도 상위에 올라왔습니다.
2. **일반법 어휘 불일치**: 민법 제390조(채무불이행), 제398조(배상액의 예정), 약관법 제7조(면책조항)처럼 **"임대차"라는 단어가 없는 일반 조문**은 임대차 문구 질의와 유사도가 낮게 나왔습니다.

### 4-3. 개선안 비교

문서 벡터만 가지고 계산하는 후처리 보정을 비교했습니다. **재학습·재임베딩은 하지 않았습니다.**

| 방법 | Hit@1 | Hit@3 | MRR@3 |
|---|---|---|---|
| 기준 (dense) | 62.5% | 70.8% | 0.667 |
| BM25 단독 (문자 2-gram) | 62.5% | 70.8% | 0.667 |
| RRF(dense + BM25) | 62.5% | 75.0% | 0.681 |
| 중심화 | 70.8% | 75.0% | 0.729 |
| 중심화 + 주성분 1개 제거 | 66.7% | 75.0% | 0.708 |
| **중심화 + 주성분 2개 제거 (채택)** | **70.8%** | **83.3%** | **0.764** |
| 중심화 + 주성분 3개 제거 | 70.8% | 79.2% | 0.750 |

집계 방식도 함께 비교했고, 조문별 **최고 점수(max)** 가 평균(Hit@1 58.3%)·합계(Hit@1 8.3%)보다 나았습니다. 키워드 혼합검색(BM25)은 Hit@3은 올렸지만 Hit@1을 떨어뜨려 채택하지 않았습니다.

### 4-4. 채택안 적용 결과

코퍼스 평균 벡터를 빼고(중심화) 상위 주성분 2개를 제거한 뒤 다시 정규화했습니다.

| 지표 | 보정 전 | 보정 후 |
|---|---|---|
| Hit@1 (strict) | 62.5% | **70.8%** |
| Hit@3 (strict) | 70.8% | **83.3%** |
| MRR@3 (strict) | 0.667 | **0.764** |
| Hit@1 (lenient) | 75.0% | **79.2%** |
| Hit@3 (lenient) | 79.2% | **91.7%** |

질의 24개 중 **7개 순위 상승, 2개 하락, 15개 동일**했습니다.

| 질의 | 쟁점 | 보정 전 → 후 |
|---|---|---|
| Q21 | 보증금 반환 지체 손해배상 | 12위 → **1위** |
| Q07 | 원상회복 범위(도배·장판) | 7위 → **1위** |
| Q16 | 위약금 과다(보증금 몰취) | 14위 → **3위** |
| Q14 | 관할 합의 | 2위 → **1위** |
| Q15 | 면책조항 | 43위 → 21위 |
| Q02 | 보증금 반환 지연 | 58위 → 34위 |
| Q20 | 신탁 부동산 | 6위 → 4위 |
| Q05 | 차임 증액 제한 | 1위 → 2위 (하락) |
| Q06 | 대항력 포기 | 4위 → 9위 (하락) |

### 4-5. 검증

- 보정 변환은 **문서 벡터만으로 계산**했고 정답 라벨을 쓰지 않았습니다. 질의에 맞춰 학습한 값이 아닙니다.
- 로컬 구현(멱반복)과 Colab의 `numpy.linalg.svd` 결과가 **지표까지 완전히 일치**했습니다.
- 초기값을 바꿔도 같은 주성분이 나와 재현성을 확인했습니다 (내적 1.000000).

## 5. 남은 문제

보정 후에도 strict 기준으로 4개 질의가 상위 3위 안에 기대 근거를 올리지 못했습니다.

- **Q02** "새 임차인이 구해져야 보증금 반환" → 기대 민법 제536조(동시이행), 34위
- **Q06** "전입신고·확정일자 포기" → 기대 주임법 제3조(대항력), 9위 (대체 근거 포함 시 3위)
- **Q15** "임대인 면책" → 기대 약관법 제7조, 21위 (대체 근거인 민법 제623조는 1위)
- **Q20** "신탁회사 소유 주택" → 기대 신탁법 제31조, 4위 (대체 근거 포함 시 1위)

공통점은 **계약 문구에는 임대차 어휘만 있고 정답 조문은 일반법 문언**이라는 점입니다. 임베딩만으로는 메우기 어려워 다음 중 하나가 필요합니다.

1. 이미 만들어 둔 **조항유형-법령 매핑표로 후보를 좁히거나 가중치 부여**
2. 유사 판례를 먼저 찾고 거기에 연결된 법령을 가져오는 경로 (팀에서 논의된 방식)
3. 조문별 검색용 키워드·요약을 사람이 추가

또한 **질의 문구에 민감**합니다. 같은 쟁점이라도 "임대인이 필요할 때마다 월세를 일방적으로 인상한다"는 민법 제626조가 1위였지만, "임대인은 필요하다고 판단하면 언제든지 차임을 인상할 수 있다"는 주임법 제7조가 1위였습니다.

## 7. 주의사항

- 점수는 코사인 유사도이며 **위험 확률이나 위법 여부가 아닙니다.**
- 기대 근거는 작성자 판단이며 법률 전문가 검수를 받지 않았습니다.
- 주성분 제거 개수(2개)는 질의 24개 기준이라 질의가 늘어나면 다시 확인해야 합니다.
- 중심벡터는 현재 법령 165청크로 계산했습니다. **코퍼스가 바뀌면 다시 계산해야 합니다.**
- 판례 벡터에는 이 보정을 적용하지 않았습니다. 적용하려면 판례 쪽에서 별도로 측정해야 합니다.
