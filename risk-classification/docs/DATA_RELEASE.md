# 공개 저장소에 포함하지 않은 자료

이 저장소에는 사례 텍스트·검수 행·예측 행을 배포하지 않는다. 파일별 이용 조건과 개인정보를 별도로 점검한 뒤 팀의 비공개 전달 경로에서 필요한 범위만 공유한다.

| 제외 경로 | 이유 |
|---|---|
| `data/raw/`, `data/processed/`, `data/examples/` | 공정위 시정 전후 요약문과 가공 자료. 출처별 이용 조건과 파생 CSV의 완전한 출처 대응 확인이 필요 |
| `data/review/`, `data/approved/`, `data/splits/` | 표준서식·요약·합성·검수 증거가 섞인 자료. 원문과 승인 증거, 로컬 경로, 검수자 정보는 공개 범위에서 제외 |
| `reports/`, `experiments/legacy_roberta/runs/` | 사례별 예측 및 오분류에 입력 텍스트가 포함될 수 있으며 내부 보고서에는 경로가 포함될 수 있음 |
| `deliverables/`, `artifacts/`, 체크포인트·ZIP·ZIP 조각 | 모델 가중치와 대용량 전달본은 팀 비공개 전달 경로 사용 |
| `.venv/`, 캐시, 임시 파일, 환경 변수, 인증 정보 | 실행 환경 및 비공개 설정 |

## 출처 확인

- [법무부 2023년 표준계약서 페이지](https://www.moj.go.kr/bbs/moj/118/575868/artclView.do)는 공공누리 1유형으로 표시된다. 이 표시는 해당 페이지의 자료에 관한 것이다. 검수 CSV는 다른 출처와 문맥 보완 초안을 함께 담으므로 통째로 배포하지 않는다.
- [국가법령정보센터 별지 제24호 서식](https://www.law.go.kr/flDownload.do?flSeq=159325999)과 [2018년 공정위 보도자료](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156269049)의 공개 페이지를 확인했다. 이 두 출처만으로 가공 후보 전체의 이용 조건이나 원계약 문구를 확인할 수 없다.
- 출처 표시, 변경 허용 범위, 제3자 권리 조건은 자료별로 검토한다. [공공누리 이용 조건](https://www.kogl.or.kr/info/license.do)

공개 파일에는 CSV 헤더, 실험 분할 ID 및 입력 파일 해시, 집계 지표만 포함한다. 합성 문장과 DRAFT에도 승인 라벨을 부여하지 않았다.
