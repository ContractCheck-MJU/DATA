# 공정위 요약문 탐색 실험

요약문 143개, 13개 출처 그룹에 동일한 5-fold 그룹 교차검증을 적용했다. 분할 기준은 `doc_id`, 시드는 42다. KLUE-RoBERTa-base를 CPU에서 배치 4, 학습률 2e-5, fold별 3 epoch로 학습하고 마지막 epoch를 사용했다.

| 모델 | 전체 검증 예측 Macro-F1 | 약라벨 1 Precision | 약라벨 1 Recall | 오분류 |
|---|---:|---:|---:|---:|
| TF-IDF + 로지스틱 회귀 | 0.8670 | 0.8649 | 0.8767 | 19/143 |
| KLUE-RoBERTa-base | 0.8741 | 0.9104 | 0.8356 | 18/143 |

혼동행렬은 행이 정답, 열이 예측이며 라벨 순서는 [0, 1]이다. TF-IDF는 `[[60,10],[9,64]]`, RoBERTa는 `[[64,6],[12,61]]`이었다. 약라벨 1을 놓친 건수는 9건에서 12건으로 늘었다. RoBERTa의 3개 fold에서 학습 손실이 낮아지는 동안 검증 손실이 높아졌다. 예측한 클래스의 모델 점수가 0.90 이상인 오분류는 16개다.

0은 시정 후, 1은 시정 전 요약문의 약라벨이다. 별도 실제 계약서 테스트셋은 없다. fold 1은 백엔드 연결 확인에 사용한 고정 모델이며 검증 성능 순위로 선정하지 않았다.
